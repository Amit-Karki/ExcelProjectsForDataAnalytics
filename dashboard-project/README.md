## 📌 Introduction

This dashboard is designed for supermarket branch managers and regional managers to monitor sales performance, compare different branches, identify the best and worst-performing product categories, and support inventory and marketing decisions.

The data used for this project was taken from Kaggle.

The following Excel skills were used in this project:

- 🔒 Workbook Protection

## 🗃️ Supermarket Dataset

The dataset was taken from Kaggle. It contains sales data from a supermarket with three different branches: A, B, and C. The data was collected over a period of three months.

### 📋 Dataset Includes:

- 👤 Gender of the Customer
- 📦 Quantity of Goods Purchased
- 💰 Total Billing Amount
- 🛒 Product Line Purchased
- 💳 Payment Method
- 👥 Customer Type
- ⭐ Customer Rating
- 🏢 Branch
- 💵 Gross Income
- 📅 And other sales-related information

# 🧩 Challenges Faced

### 🔒 1. Sheet Protection

Initially, I did not know that the **Edit Objects** option had to be disabled when protecting the worksheet so that charts could not be moved or deleted.

I used Claude AI to help me understand and solve this issue.

### 📝 2. Text Box Issue

I initially tried to display the KPI values using formulas inside text boxes. However, after changing the formatting, such as increasing the text size, the formula did not update properly when I changed the input values such as branch or gender.

I tried different solutions, including disabling hardware/graphic acceleration and manipulating the workbook using code, but these solutions did not work for my case.

Eventually, I used **Merge & Center** along with borders to display the KPI values properly.

### ⚠️ 3. Data Validation and Trailing Spaces

I faced an issue with the Gender Data Validation option for `M`. The value contained trailing spaces, which caused the formulas to treat it as a different value.

As a result, when `M` was selected, the formula returned zero for the total customer count.

I identified the trailing-space issue and corrected it so that the formulas could work properly with the selected value.
